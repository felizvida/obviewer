# Support

## Using the app

- Install and first-run help: [`docs/INSTALL.md`](docs/INSTALL.md)
- Known limitations: [`docs/STATUS.md`](docs/STATUS.md)
- If the reader is blank or behaves oddly, choose **Help › Copy Reader Diagnostics** and paste the text into your issue.

When reporting a problem, include:

- your macOS version
- your Mac model (Obviewer supports Apple silicon Macs only)
- the Obviewer version (Obviewer › About)
- the kind of source you opened: a single file, a Markdown folder, an Obsidian vault or a DokuWiki

A minimal note that reproduces the problem helps most. Please remove anything private first.

## Building from source

- Use full Xcode, not just the Command Line Tools (`xcode-select -p`).
- See [`QUICKSTART.md`](QUICKSTART.md) and [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md).

## Where to ask

- GitHub Issues, for concrete bugs and feature requests
- Security problems: see [`SECURITY.md`](SECURITY.md) and don't open a public issue
